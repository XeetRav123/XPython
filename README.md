# ⚡ XPython
**Python IDE for Android** — Neon Glass Purple Theme

XPython is a full-featured Python 3.13 IDE built for Android using a WebView shell.
It supports syntax highlighting, autocomplete, pip package management, SAF file access, and APK building.

## Project Structure
```
XPython/
├── web/          # WebView frontend (HTML/CSS/JS)
├── app/          # Android WebView APK wrapper
├── python-runtime/ # Python runtime bridge
└── docs/         # Documentation
```

## Build
GitHub Actions handles the build pipeline. See `.github/workflows/build.yml`.

## Design
**Neon Glass Python** — dark background, purple neon, glass panels, bloom effects, particle animations.
